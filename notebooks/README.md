# Notebooks del proyecto

Esta carpeta contiene los notebooks de Google Colab utilizados para el desarrollo y la ejecución del proyecto Monitoreo de Fauna con YOLOv8.

- `Monitoreo_Fauna_YOLOv8.ipynb`: notebook original de trabajo.
- `Monitoreo_Fauna_YOLOv8_limpio.ipynb`: versión organizada y documentada para la ejecución reproducible del proyecto.

La versión limpia se preparará reutilizando los modelos y resultados existentes en Google Drive, sin necesidad de repetir el entrenamiento.
